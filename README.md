One line of the worst possible advice an AI could give, in 140 characters or fewer: asked about a car that won't start, it cheerfully recommends pouring coffee in the tank — because it's basically fuel, just bean-flavoured. The joke lands on the confident, helpful tone of a real AI assistant giving one specific, concrete, catastrophically wrong fix, instead of leaning on the password, database, microwave, WD-40, smoke-alarm or wet-phone angles the rest of the field has already worn out.

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), UTF-8, with no trailing newline. Python 3.13, standard library only, deterministic, no network.
